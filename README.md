# 📚 RAG 个人知识库问答助手 v2.0

基于 RAG（检索增强生成）技术的智能问答系统，支持上传 PDF/TXT/DOCX 文档，通过多策略检索、重排序、查询改写和强制引用，提供准确、可信的答案。

## ✨ 功能特点

- 支持多种文档格式（PDF、TXT、DOCX）
- **灵活切分策略**：固定长度、按句子、按段落，适应不同文档结构
- **相似度阈值过滤**：自动丢弃低相关片段，减少噪音
- **重排序（Rerank）**：使用 BGE-reranker 精排候选片段，提升 Top-1 准确率
- **查询重写**：将模糊、口语化问题转化为规范检索词，提高召回率
- **强制引用与防幻觉**：答案中标注来源【数字】，无相关内容时明确拒答
- **前端高亮展示**：引用编号高亮，来源可折叠查看
- **自动化评估**：内置测试集，量化优化效果

## 🛠️ 技术栈

- **后端**：FastAPI, Chroma, requests
- **前端**：Streamlit
- **嵌入模型**：硅基流动 BAAI/bge-m3（免费）
- **重排序模型**：硅基流动 BAAI/bge-reranker-v2-m3（免费）
- **大模型**：DeepSeek API / 硅基流动（可配置）

## 🚀 快速开始

1. 克隆仓库并安装依赖
2. 配置 `.env`（API_KEY, BASE_URL, SF_API_KEY）
3. 启动后端：`uvicorn main:app --reload`
4. 启动前端：`streamlit run app.py`
5. 访问 `http://localhost:8501` 使用
